1. ¿Qué es Windows Forms?

Windows Forms (WinForms) es una tecnología de .NET para crear aplicaciones de escritorio con interfaz gráfica: ventanas, botones, cuadros de texto, listas, etc. Es ideal para aprender porque puedes ver el resultado de tu código de inmediato.

Diseñador visual
Arrastras controles desde el Cuadro de herramientas y los acomodas en el formulario.
Programación por eventos
Tu código se ejecuta cuando el usuario hace algo: clic, escribir, seleccionar…
Lenguaje C#
Escribes la lógica (cálculos, validaciones, decisiones) en C#.
Idea clave: en consola el programa dicta el orden. En Windows Forms, el usuario decide qué pasa y cuándo; tu programa reacciona.

2. Preparar el entorno

  1. Instala Visual Studio Community (gratuito) y marca la carga de trabajo "Desarrollo de escritorio con .NET".
  2. Abre Visual Studio → Crear un proyecto.
  3. Elige la plantilla Aplicación de Windows Forms (C#). Cuidado: no elijas la de ".NET Framework" a menos que tu clase lo pida.
  4. Ponle un nombre (por ejemplo MiPrimerForm) y pulsa Crear.

5. Eventos

Un evento es algo que ocurre (clic, tecla, cambio de texto). El método que responde se llama manejador de eventos (event handler).

EventoSe dispara cuando…
ClickEl usuario hace clic.
TextChangedCambia el texto de un TextBox.
KeyPressSe presiona una tecla.
LoadEl formulario se está cargando.
SelectedIndexChangedCambia la selección de una lista.
CheckedChangedSe marca/desmarca un CheckBox o RadioButton.

Cómo crear un manejador: haz doble clic sobre el control en el diseñador (crea el evento por defecto), o abre Propiedades → ⚡ y haz doble clic junto al evento deseado.

private void btnSaludar_Click(object sender, EventArgs e)
{
    // se ejecuta cada vez que se hace clic en btnSaludar
}
  • sender: el control que originó el evento.
  • e: información adicional del evento.

Ejemplo: aceptar solo números en un TextBox

private void txtEdad_KeyPress(object sender, KeyPressEventArgs e)
{
    // Permite dígitos y la tecla Retroceso
    if (!char.IsDigit(e.KeyChar) && e.KeyChar != (char)Keys.Back)
    {
        e.Handled = true;   // cancela la tecla
    }
}

8. Conversión y validación de datos

El Text de un TextBox siempre es string. Para calcular necesitas convertirlo a número.

MétodoComportamiento
int.Parse(txt)Convierte, pero lanza excepción si el texto no es válido.
int.TryParse(txt, out n)Recomendado. Devuelve true/false y no truena el programa.
Convert.ToInt32(txt)Similar a Parse; también lanza excepción.
private void btnCalcular_Click(object sender, EventArgs e)
{
    if (int.TryParse(txtEdad.Text, out int edad))
    {
        lblResultado.Text = $"El próximo año tendrás {edad + 1} años.";
    }
    else
    {
        MessageBox.Show("Escribe un número entero válido.", "Dato incorrecto",
                        MessageBoxButtons.OK, MessageBoxIcon.Warning);
        txtEdad.Focus();
    }
}

Validar que no esté vacío

if (string.IsNullOrWhiteSpace(txtNombre.Text))
{
    MessageBox.Show("El nombre es obligatorio.");
    return;   // sale del método
}

try / catch

try
{
    int n = int.Parse(txtNumero.Text);
    lblResultado.Text = (100 / n).ToString();
}
catch (FormatException)
{
    MessageBox.Show("Eso no es un número.");
}
catch (DivideByZeroException)
{
    MessageBox.Show("No se puede dividir entre cero.");
}

10. Ciclos

CicloCuándo usarlo
forSabes cuántas veces repetir.
whileRepites mientras se cumpla una condición.
do…whileComo while, pero se ejecuta al menos una vez.
foreachRecorrer colecciones (listas, arreglos).

Tabla de multiplicar en un ListBox

private void btnTabla_Click(object sender, EventArgs e)
{
    if (!int.TryParse(txtNumero.Text, out int n)) return;

    lstResultados.Items.Clear();
    for (int i = 1; i <= 10; i++)
    {
        lstResultados.Items.Add($"{n} x {i} = {n * i}");
    }
}

Suma acumulada con while

int contador = 1, suma = 0;
while (contador <= 100)
{
    suma += contador;
    contador++;
}
lblResultado.Text = $"La suma de 1 a 100 es {suma}";
Evita ciclos infinitos: un while sin modificar la condición congela la ventana. Si pasa, detén la depuración con Shift + F5.

14. Proyecto guiado: calculadora básica

Controles: dos TextBox (txtA, txtB), un ComboBox (cmbOperacion) con + − × ÷, un Button (btnCalcular) y un Label (lblResultado).

Form1.cs 
public partial class Form1 : Form
{
    public Form1()
    {
        InitializeComponent();
    }

    private void Form1_Load(object sender, EventArgs e)
    {
        cmbOperacion.Items.AddRange(new string[] { "+", "-", "*", "/" });
        cmbOperacion.SelectedIndex = 0;
        cmbOperacion.DropDownStyle = ComboBoxStyle.DropDownList;
    }

    private void btnCalcular_Click(object sender, EventArgs e)
    {
        if (!double.TryParse(txtA.Text, out double a) ||
            !double.TryParse(txtB.Text, out double b))
        {
            MessageBox.Show("Ingresa dos números válidos.", "Error",
                            MessageBoxButtons.OK, MessageBoxIcon.Warning);
            return;
        }

        double resultado = 0;
        switch (cmbOperacion.SelectedItem.ToString())
        {
            case "+": resultado = a + b; break;
            case "-": resultado = a - b; break;
            case "*": resultado = a * b; break;
            case "/":
                if (b == 0)
                {
                    MessageBox.Show("No se puede dividir entre cero.");
                    return;
                }
                resultado = a / b;
                break;
        }

        lblResultado.Text = $"Resultado: {resultado:N2}";   // 2 decimales
    }
}
Reto extra: agrega un botón "Limpiar" que borre los campos y devuelva el foco a txtA. Pista: txtA.Clear(); y txtA.Focus();.

16. Buenas prácticas

  • Nombra los controles con prefijo y significado: txtApellido, btnGuardar.
  • Valida siempre lo que escribe el usuario antes de operar con ello.
  • Separa la lógica de la interfaz: crea métodos aparte (por ejemplo CalcularPromedio(...)) en lugar de escribir todo dentro del evento.
  • Usa comentarios para explicar el porqué, no lo obvio.
  • Una acción, un método: métodos cortos son más fáciles de depurar.
  • Prueba casos límite: vacío, cero, negativos, números muy grandes.
  • Configura TabIndex y AcceptButton del formulario para que la app se pueda usar con teclado.

Ejemplo: separar lógica de la interfaz

// Lógica reutilizable
private double CalcularPromedio(double n1, double n2, double n3)
{
    return (n1 + n2 + n3) / 3;
}

// Evento solo coordina
private void btnPromedio_Click(object sender, EventArgs e)
{
    if (double.TryParse(txtN1.Text, out double a) &&
        double.TryParse(txtN2.Text, out double b) &&
        double.TryParse(txtN3.Text, out double c))
    {
        lblPromedio.Text = CalcularPromedio(a, b, c).ToString("F2");
    }
}

17. Ejercicios propuestos

Conversor de temperatura

Convierte °C a °F con la fórmula F = C × 9/5 + 32. Valida que el dato sea numérico.

Número par o impar

Pide un entero y muestra si es par o impar usando el operador %.

Promedio de calificaciones

Tres TextBox de notas. Muestra el promedio y si el alumno aprueba (≥ 70) o reprueba.

Tabla de multiplicar

Genera la tabla del número ingresado en un ListBox usando for.

Lista de tareas

Agrega y elimina elementos de un ListBox. Muestra cuántas tareas hay en un Label.

Login simple

Usuario y contraseña (con PasswordChar). Si son correctos, abre un segundo formulario con un saludo; si no, muestra un MessageBox de error.

Tienda con descuento

Producto, cantidad y un CheckBox "Cliente frecuente" (10% de descuento). Calcula subtotal, IVA (16%) y total.

Adivina el número

La app elige un número aleatorio del 1 al 100 (new Random().Next(1, 101)). El usuario intenta adivinar y se le indica si es mayor o menor. Cuenta los intentos.
